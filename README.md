# ArYSL: Yemeni Sign Language Recognition

مشروع نظام ذكاء اصطناعي للتعرف على لغة الإشارة اليمنية وترجمتها.

## 🛠️ التقنيات المستخدمة
- **قاعدة البيانات:** PostgreSQL 18
- **الخلفية (Backend):** FastAPI (Python)
- **الواجهة (Frontend):** Next.js + React + Tailwind CSS
- **الذكاء الاصطناعي:** PyTorch (EfficientNet)

## 📂 هيكل المشروع
- `/backend`: كود الـ API ونموذج الذكاء الاصطناعي.
- `/frontend`: واجهة المستخدم.
- `/docs`: ملفات التوثيق والتقارير.
